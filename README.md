to run this:
1. have code on puter
2. have SDR plugged into puter

SOFTWARE
venv (ON MAC):
1. make a virtural python environment called `.venv`: ``python3 -m venv .venv``
2. activate the venv ``source .venv/bin/activate``
3. install dependancies in the venv: ``pip3 install  -r requirements.txt``
4. run it: ``python3 -m main``


this should work assuming you have python 3.13+
